Sleep Quality Predictor
A Machine Learning–based web application that predicts sleep quality and provides personalized lifestyle advice using health and behavioral data.

 Project Overview
Sleep plays a vital role in physical and mental health. Poor sleep quality can lead to stress, obesity, heart problems, and reduced productivity.
This project predicts a person’s sleep quality based on daily habits and health parameters and gives actionable suggestions to improve sleep.

 Features
Predicts sleep quality (Poor / Average / Good)
Uses lifestyle and health-related inputs
Provides personalized sleep improvement advice
Simple and interactive Streamlit web interface
Can be extended to mobile or web-based wellness apps

 Machine Learning Details
Type: Supervised Learning (Classification)
Algorithm Used: Random Forest Classifier
Target Variable: Quality of Sleep
Dataset: Sleep Health and Lifestyle Dataset (Kaggle)

 Technologies Used
Language: Python

Libraries:
pandas, NumPy – data preprocessing
scikit-learn – model training & evaluation
matplotlib, seaborn – data visualization
streamlit – web application
